
# 🧮 GUI Calculator - Java Applet

A functional calculator application built using Java Applet and AWT.

## ✨ Features
- Basic Operations: +, -, *, /, %
- Advanced Functions: SQRT, ABS  
- Clear & Backspace functionality
- Exception handling for divide by zero

## 🛠️ Tech Stack
- Core Java
- Java Applet  
- AWT (Abstract Window Toolkit)
- Event Handling

## 🚀 How to Run
```bash
javac Calculator1.java
appletviewer Calculator1.java
